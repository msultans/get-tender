# get-tender

Конвейер и рабочее место для отработки тендеров. Первая площадка — **zakup.sk.kz**
(закупки группы Самрук-Казына). Дальше — остальные площадки.

Система делает то, что сейчас делается руками: сама обходит портал, скачивает
документацию по всем лотам, отсеивает неподходящие по правилам, разбирает
оставшиеся по пайплайну, считает экономику, поднимает историю закупок и
конкурентов — и будит человека только тогда, когда лот действительно стоит
внимания.

## Статус

Проектирование. Кода нет. Ближайшая задача — спайк харвестера
(см. [07-mvp.md](docs/07-mvp.md), Ш-0): подтвердить, что портал стабильно
обходится headless-браузером. Пока это не подтверждено, остальной план — гипотеза.

## Источник знаний

Экспертная часть (что искать в документации, как считать экономику, где прячутся
барьеры) взята из скилла `samruk-tender-analysis`, наработанного на живых
тендерах. Скилл остаётся источником правды по методике разбора; ТЗ описывает,
как эту методику превратить в конвейер.
